Free, public RPC and API endpoints operated by GATA HUB. No key or registration
is needed.

:::note
[gatahub.zone](https://gatahub.zone/#infrastructure) is the reference for what is
currently running, with live status per endpoint. This page mirrors it.
:::

## Decommissioned

**All gRPC endpoints have been retired.** The `*-grpc.gatadao.com` addresses this
page previously listed no longer resolve.

Endpoints are no longer operated for these networks: Archway, Cosmos Theta
Testnet, Dymension, Elys, Evmos, GovGen, Namada, Neutron, Omniflix, Stargaze,
Stride and Teritori.
